# Cadastro-Web

Web-based parts registration CRUD: a Java EE back end (JPA entities, JAX-RS resources,
bean validation) with an AngularJS front end and PostgreSQL schema scripts.

| Path | Contents |
| --- | --- |
| `CRUD-back/` | Java EE back end — `Produto` and `Movimentacao` entities, service layer, REST configuration |
| `CRUD-banco/` | Database creation and seed SQL, datasource and driver definitions |
| `index.html`, `js/` | AngularJS front end |
